# 原創篇實驗（為 `新遊戲企劃100款_原創篇.md` 做的出題器與對戰實測）

用 Node 執行（`node 檔名.cjs`），不需要安裝任何套件。隨機數都用固定種子，重跑結果一樣（只有耗時不同）。
所有輸出已經收在 `結果.txt`（重跑全部：在這個資料夾依序執行每一支 `exp_*.cjs`）。

| 檔案 | 測什麼 | 用在企劃的哪幾款 |
|---|---|---|
| `exp_duels.cjs` | 人機對戰：先後手誰贏、有沒有公式、「直覺走法」會不會輸；以及刪掉的拔河選人、電梯搶一樓 | 581～590 |
| `exp_place.cjs` | 擺擺看：唯一解的比例、最少要給幾個提示、某些規則根本不可能；以及刪掉的扁擔挑擔 | 533～539、586 |
| `exp_probe.cjs` | 問一次得一條：最壞情況最少要問／敲／驗幾次、答案唯一的比例 | 545、549、552、553、615 |
| `exp_money.cjs` | 最划算：直覺做法跟最好的做法差多少、多常有巧思可用 | 556、557、560、563 |
| `exp_impl8.cjs` | 2026-11-02 實作使用者圈的 8 款前的實測：撲滿唯一解比例與答案會不會偏向 1 或 9、疊箱子最少露幾箱與「照大小排就對」的比例、形色不相鄰的擺法數、按鍵搶三十的必勝步數 | 525、538、542、582 |
| `lint_plan.cjs` | 檢查企劃文件：編號連續、id／名稱和現有遊戲與舊企劃不撞、欄位齊全、每款寫出「最像」、統計各類數量 | 整份文件 |

`exp_place.cjs` 可以只跑其中幾項：`node exp_place.cjs pricetags,boxstack`。
`lint_plan.cjs` 預設檢查上一層的 `新遊戲企劃100款_原創篇.md`：`node lint_plan.cjs`。
