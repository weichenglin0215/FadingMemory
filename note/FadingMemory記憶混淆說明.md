> 版本紀錄：

> - 第 2 版：記錄已決定的事（第 7 節），並新增紙條的寫法（第 8 節）、題目與誘答的產生方式（第 9 節）、第 6 關範例（第 10 節）。

## 0. 一句話結論

**記憶不是錄影，而是每次重新「拼」出來的。**
拼的時候，會發生這些事：
- 相似的碎片被拿錯。
- 來源記錯。
- 順序排錯。
- 空白被「合理的猜測」補上。

所以要分清兩件事：
- **忘記**：想不起來，答「不知道」。
- **混淆**：很有把握地想起**錯的東西**，而且自己不覺得錯。

回家的路真正要練的是後者。現實生活裡最麻煩的也是後者，例如把昨天的停車位當成今天的、藥吃過了又吃一次、搭上號碼很像的公車。

## 1. 記憶的三個階段，各自怎麼出錯

| 階段 | 大腦在做什麼 | 會怎麼錯 | 在「回家的路」裡的例子 |
|---|---|---|---|
| **記進去**（編碼） | 注意、理解、把零件綁在一起 | 沒注意到；一次塞太多（工作記憶大約只能同時抓 4 個單位）；零件分開存了，但「誰配誰」沒綁牢 | 記得有「三樓」也有「手鐲」，卻沒綁住「手鐲在三樓」 |
| **放著**（保存） | 慢慢固定下來 | 時間越久細節越淡；**後來學到的相似東西會覆蓋、干擾原本的** | 搭了三趟公車之後，三個號碼互相干擾 |
| **叫出來**（提取） | 用線索把記憶重建出來 | 線索同時指向好幾個記憶；「覺得熟悉」被誤當成「就是它」；用常理補空白 | 看到 263 覺得眼熟（因為 236 很像）就選了 |

## 2. 為什麼會混淆：13 個機制

每一項都列出白話說明、學術名稱，以及在遊戲裡可以怎麼出現。

### 2.1 越像越容易搞混（相似性干擾）
- 兩個記憶越相似，越容易互相干擾。可能是外形、聲音、意思相似，也可能是同一類東西。
- 最容易錯的情況，是**同一個線索配了不同答案**：心理學稱為 A-B／A-C 干擾，例如「第一段公車」和「第二段公車」。
- 大腦有個功能叫**型態分離**（pattern separation），負責把很像的經驗分開存。這個功能會隨年紀退化，對 236／263 這種「幾乎一樣」的誘答特別敏感。
- 例子：236／263／326；衡陽路／恆陽路；三樓／四樓。

### 2.2 舊的干擾新的、新的干擾舊的（前向干擾／後向干擾）
- **前向干擾**：以前記的東西，擋住新的。例如昨天停車的位置，讓你想不起今天停在哪。
- **後向干擾**：新學的東西，蓋掉舊的。例如換了新電話號碼，就想不起舊號碼。
- 同一類的東西連續出現，干擾會一路累積。**換一類**，干擾會突然消失，這叫「干擾釋放」（Wickens）。
- 臨床研究發現：「被前一份相似清單干擾之後，還能不能恢復」，是阿茲海默症很早期就會出問題的能力（LASSI-L 測驗）。
- 例子：先記一張紙條、做完，再給第二張相似的紙條。第二張會被第一張干擾；問第一張時，又會被第二張干擾。

### 2.3 零件記得，組合錯了（綁定失誤）
- 大腦把顏色、形狀、數字、位置分開存，「誰配誰」要另外綁。綁得不牢，就會出現**錯誤組合**：記得有紅色、有三角形，也有藍色圓形，最後卻變成「紅色圓形」。
- 年紀大之後，「單一事實」記得還不錯，但「兩件事的關聯」明顯變差，這叫聯結缺損假說（Naveh-Benjamin）。
- 研究發現：**顏色＋形狀的短期綁定**在阿茲海默症很早期就會受損，正常老化卻相對不受影響（Parra 等人）。所以這是最值得練的題型之一。
- 例子：墨綠色手鐲、黃色盒子、綠色招牌……；問「墨綠色的是哪一個？」

### 2.4 記得內容，記錯出處（來源混淆）
- 記得「蛋糕店要右轉」，但不記得是紙條寫的、路人說的、招牌上看到的，還是上一局的。
- 老年人特別容易出現來源錯誤，而且常常是**高信心**的錯。
- 例子：紙條寫 758，公車站的路人說「去蛋糕店搭 752 比較快」。之後問：「紙條上寫的是幾號？」
- **已決定不使用「路人說錯的話」**。混淆一律來自紙條本身的文句，見 8.2 的 F。

### 2.5 「好眼熟」不等於「就是它」（熟悉感誤認）
- 記憶有兩種訊號：
  - **熟悉感**：好像看過。
  - **回想**：想得起是在哪裡、怎麼看到的。
- 老化時熟悉感大致保留，回想會退化。所以選擇題的誘答只要「看起來眼熟」，就很容易選錯。
- 最重要的出題原則：**誘答若從沒在紙條出現過，玩家只要靠「眼不眼熟」就能答對，題目就很簡單。誘答若是紙條裡的真資訊、只是放錯了位置，就一定要靠回想。**
- 例子：問「百貨公司在幾樓？」，選項放「3 樓、12 樓、2 樓、5 樓」。其中 12 是門牌號碼，2 是「過兩個巷子」裡的 2，全都在紙條上出現過。

### 2.6 記得大意，細節被換掉（要點記憶／錯誤記憶）
- 大腦同時存「大意」和「字面」。字面忘得快，大意留得久，這叫模糊痕跡理論。
- 學一串相關的詞，例如床、休息、打盹、枕頭，事後常會「確定」自己看過一個其實沒出現的詞：睡覺。這是有名的 DRM 錯誤記憶實驗。
- 例子：紙條寫「巧克力蛋糕」，誘答放「黑森林蛋糕」。兩者大意都是巧克力蛋糕，只有字面不同。

### 2.7 用常理把空白補起來（基模）
- 想不起來的地方，大腦會用「通常是這樣」來補，而且補完自己察覺不到。
- 例子：
  - 台灣的百貨公司，珠寶精品**通常在 1 樓**。紙條寫「三樓買手鐲」時，常理就會把人拉回「1 樓」。
  - 「蛋糕店」常理上在賣麵包的店旁邊。
- 出題時**故意讓紙條內容違反常理**，可以測到「是真的記得，還是用猜的」。

### 2.8 順序排錯（序列與時間混淆）
- 「有哪幾件事」比「先後順序」好記。
- 順序出錯時，通常是**和鄰居對調**：第 3 件和第 4 件互換，很少第 1 件跑到最後。
- 中間的項目最難記，因為有頭尾效應：頭尾比較好記。
- 同類事件重複發生時，例如搭三次公車、轉兩次彎，最容易弄亂「哪一次是哪一個」。
- 例子：「開封街右轉、漢口街左轉」被記成「開封街左轉、漢口街右轉」。方向沒忘，只是配對對調了。

### 2.9 「不要」被記成「要」；改過的計畫被舊版蓋回去（否定與更新）
- 句子裡的「不」是額外貼上去的標籤，忙或時間一久，標籤就掉了。
- 研究發現：長者聽過「某說法是錯的」，隔幾天後，反而更可能記成「那是對的」。
- 計畫改過之後，舊版本會一直跑出來。這是前向干擾的一種。
- 例子：
  - 「**不要**在南門市場下車」。
  - 「原本 3 點，改成 4 點」。
  - 「蛋糕改成草莓口味」。

### 2.10 同一個線索掛太多東西（扇形效應／線索過載）
- 一個東西身上的資訊越多，要取出其中任何一個就越慢、越容易拿錯。
- 例子：「蛋糕」身上同時掛著店名、口味、盒子形狀、顏色、價格、取貨時間。問「蛋糕的盒子是什麼形狀？」時，其他幾項都在搶答。

### 2.11 做過了沒？該做的時候忘了做（前瞻記憶與輸出監控）
- **前瞻記憶**：記得「將來某個時間點要做某事」，例如出百貨公司後要傳簡訊。
  - 用「事件」提醒的比較好記，例如「看到郵筒時」。
  - 用「時間」提醒的比較難，例如「5 點半時」。長者尤其如此。
- **輸出監控**：記得自己**已經做過**沒。長者常重複講同一個故事、不確定藥吃過沒。
- **習慣劫持**：熟悉的路線或動作把你帶走。例如本來要先去蛋糕店，卻順著平常的路直接回家。

### 2.12 名字特別難記（專有名詞）
- 「他是一位麵包師傅」比「他姓麵包」好記得多，即使是同一個詞。這叫 Baker-baker 悖論。
- 原因：職業、類別有意義可以連結，名字是任意的。店名、路名、公車號碼都屬於「任意」的資訊，是最容易混淆的一類。

### 2.13 台灣長者特有的混淆來源（數字、中文字、語音）

| 類型 | 例子 |
|---|---|
| 數字調換位置 | 236／263／326；十三／三十 |
| 聲音相近 | 四／十（台灣國語常不分捲舌）；一／七（所以台灣念電話號碼常把 1 念成「么」） |
| 字形相近 | 6／9（倒過來）、1／7、3／8；己／已、未／末、大／太 |
| 同字首、同類別的路名 | 漢口街／漢中街；台北西區一整片都是用中國城市命名的路，例如武昌、開封、長沙、桃源、漢口，彼此很容易混 |
| 左右 | 轉身之後的左右、鏡像；「右手第三間」要以哪個方向為準 |
| 時間 | 下午 7 點／19:00；7:30／7:13 |

## 3. 哪些狀況最容易混淆（檢核表）

出題時，可以把下面每一項當成一個「旋鈕」，轉大就變難。

| 類別 | 旋鈕 | 越怎樣越容易混淆 |
|---|---|---|
| 材料本身 | 相似度 | 數字、名稱、外形、意思越像 |
| | 同類數量 | 同一類東西越多，例如三班公車、三家店 |
| | 共用特徵 | 好幾個東西共用同一個顏色、形狀或數字 |
| | 一物多資訊 | 一個東西身上掛的細節越多 |
| | 違反常理 | 內容越違反一般習慣 |
| | 否定、更正 | 有「不要」「改成」「除了」 |
| 呈現方式 | 來源數量 | 同一件事有多個來源說法（紙條、路人、招牌） |
| | 誘答來源 | 誘答來自紙條本身（真資訊放錯位置） |
| | 題目順序 | 問的順序和記的順序不同 |
| 時間安排 | 延遲 | 記完到被問之間越久 |
| | 中間插入 | 中間插入其他要動腦的事，例如心算、另一件差事 |
| | 前一局干擾 | 上一局剛玩過相似但不同的內容 |
| 玩家狀態 | 時間壓力、分心、疲勞、焦慮 | 越緊張、越累越容易混 |

## 4. 年紀與失智：哪些會變、哪些不太變

| | 正常老化 | 失智早期（以阿茲海默症為例） |
|---|---|---|
| 大意、常識、字彙 | 大致保留，甚至更好 | 早期尚可 |
| 單一事實的再認（選擇題） | 大致保留 | 下降 |
| **兩件事的關聯（綁定）** | **下降** | **明顯下降**；顏色＋形狀綁定特別敏感 |
| 來源記憶 | 下降，常有高信心錯誤 | 明顯下降 |
| 抑制無關資訊 | 下降，誘答更容易「闖進來」 | 明顯下降；答案中常出現沒出現過的內容 |
| 很像的東西分辨（型態分離） | 下降 | 明顯下降 |
| 延遲後的回想 | 稍降 | **最敏感的指標之一**：幾分鐘後就想不起來，給提示也幫助有限 |
| 被干擾後恢復 | 可以恢復 | 很難恢復（LASSI-L） |

**設計上要注意的一件事：「無錯誤學習」**
- 記憶力受損的人，會把**自己犯過的錯**當成新的記憶學起來。原因是他記得答案，卻不記得那是錯的。
- 所以：
  - 題目製造混淆，是為了「練習分辨」，**不是為了讓人一直錯**。
  - 答錯後要清楚給正確答案和理由，例如「236 和 263 很像，紙條上寫的是 236」。
  - 同一關重玩時題目不變（你的規則 3），剛好能讓玩家把**正確的**版本記牢，不會每次都被新的錯誤干擾。**這條規則在科學上是對的。**

**誠實說明**：目前的研究顯示，記憶訓練對「練過的那種作業」有效。能不能延伸到日常生活、能不能預防失智，證據仍有限。這個遊戲的價值是規律的動腦練習、覺察自己容易錯在哪裡，以及好玩。

## 5. 這對出題的意義（原則，還不是題目）

### 5.1 現在的題目為什麼太簡單（第 4～8 關）
對照上面的機制，目前題目的問題是：

1. **每個東西都是獨一無二的**。
   - 第 5 關：紅色只有原子筆、三角形只有資料夾。
   - 第 7 關：寄信、搭公車、買菜、繳電費，意思差很遠。
   - 結果是沒有相似性干擾，也不需要綁定。
2. **誘答大多沒在紙條出現過**。
   - 例如「600／700／800／900 元」「義美／85 度 C」「336／536」。
   - 玩家只靠「眼不眼熟」就能答對，考的是熟悉感，不是回想。
3. **數字誘答是等距鄰居**（25／30／35／40）。答案常常剛好落在中間，猜也猜得中。
4. **題目順序跟紙條順序幾乎一樣**，紙條的順序本身就變成提示。
5. **題與題彼此獨立**。每題只問一件事，沒有「要把兩件事接起來才答得出來」的題。
6. **同一件事問很多次**。例如第 7 關的棗紅色／墨綠色問了 4 題，第 2 題之後就不算考記憶了。
7. **前瞻記憶用「回想題」來考**（「什麼時候傳簡訊？」）。這其實沒有考到前瞻記憶：真正的前瞻記憶是**時候到了會不會自己想起來做**。

### 5.2 新的出題原則
1. **每個錯誤選項都要有「來歷」**：誘答要對應到某個混淆機制。

   以「第一段搭幾號？」（答案 236）為例：

   | 誘答 | 來歷 |
   |---|---|
   | 263 | 鄰位對調（2.8、2.13） |
   | 326 | 數字換位（2.13） |
   | 758 | 另一段的公車（2.1 A-B／A-C） |
   | 12 | 紙條上別的數字（2.5 熟悉感） |

   這樣玩家答錯時，我們知道他是**被哪一種混淆**騙到。結果頁可以從「8 種記憶類型」升級成「你比較容易被＿＿混淆」。
2. **一關＝一個故事，東西成對出現**：兩班公車、兩家很像的店、兩個禮物、兩個時間。這樣題目之間才有**相關性**與**相似性**，這正是你指出的缺點。
3. **要把兩件事接起來才答得出來**。例如「買蛋糕的那一站，前一站是哪裡？」「紅色的東西是在第幾件事買的？」
4. **打亂問的順序**，並在紙條與題目之間**插入一段干擾作業**，例如簡單心算或另一件小差事。
5. **加入新的題型**：來源題（誰說的？）、更正題（改過之後是？）、否定題（哪一站**不能**下車？）、真前瞻題（題目進行中，看到某個訊號時要按某個鍵）、「做過了沒」題。
6. **難度＝混淆強度，不只是題數**。

### 5.3 難度階梯（方向已同意；紙條的字數、頁數、寫法見 8.3）

| 關 | 題數 | 主要練的混淆 | 故事骨架（示意） |
|---|---|---|---|
| 1 | 4 | 幾乎沒有干擾，建立信心 | 一件事：一班車、一個樓層 |
| 2 | 6 | 數字相似（對調） | 兩件事，兩個數字很像，例如 15 號公車、51 號門牌 |
| 3 | 8 | 順序（鄰位對調） | 三件同類的事，例如三家店，考先後 |
| 4 | 12 | 顏色＋形狀綁定 | 四樣東西、只用三種顏色三種形狀，共用特徵 |

### 6.3 建議做法（技術面，先記下來）
- 進入時產生一個**亂數種子**，並把**整份產生好的內容**存進瀏覽器，不是只存種子。原因是遊戲會自動更新版本：只存種子的話，新版的產生方式一改，同一個種子會變出不同的題目。
- 保存種子的好處：陪伴的家人或照護者可以「重現」同一局。
- 新一局的多值參數（號碼、名稱、物品）要避開上一局用過的值，才能保證「全部都改變」。
- 二選一的參數（左轉／右轉）**已決定**：隨機即可，不必刻意和上一局不同。
- **換題本身就是一種訓練**：新一局的 236 變成 318 時，上一局的 236 會跑出來干擾（前向干擾）。這就是現實裡「昨天的停車位」問題，是很有價值的練習。

### 6.4 正式模式（3D）的變動方式
- 3D 裡的招牌、站牌、門牌都是程式即時畫的文字貼圖，換名字、換號碼在技術上沒問題。
- 建議分兩階段：
  1. **換文字**：公車號、站名、店名、樓層、禮物、蛋糕、門牌。地圖不變。
  2. **換路線**：轉彎方向、第幾條巷子、店在路的哪一邊。地圖要改成可組合，工作量較大。
- 3D 場景裡要同時放進**誘答**，讓混淆發生在「現場」：
  - 進站的公車號碼很像（236／263／326）。
  - 百貨公司裡有兩家很像的店。
  - 路口的路名同字首（漢口街／漢中街）。

## 8. 紙條（任務說明）的寫法

### 8.1 為什麼要改
現在的紙條，其實是「已經幫玩家整理好的重點摘要」：
- 有編號、一行一件事、沒有廢話。
- 最花腦力的「從一大段話裡挑出重點、整理、記住、再更新」，已經先替玩家做完了。
- 編號①②③本身就是順序的提示。

現實生活裡，交代事情是這樣的：老伴在門口邊穿鞋邊講、講到一半想起別的事、順便抱怨上次買錯、最後又打電話來改。**把這些話整理成重點，本身就是記憶的工作**，也是最容易出錯的地方。

所以：
- 第 1 關維持精簡條列，讓玩家熟悉玩法。
- 從第 2 關開始改成口語、字數變多、頁數變多。
- 第 6～8 關出現「前面講、後面改」的跨頁更改，並夾雜看起來像重點、其實不會考的話。

### 8.2 九種混淆寫法
A～E 是你提出的，F 是你答覆第 2 題時提的，G～I 是我補充的。

#### A. 多屬性描述（一個東西掛很多特徵）
- 例：放在**櫃子上方**、畫著**紅色線條**、**有蓋子**的**橢圓形透明玻璃**瓶。
- 拆成元素：

  | 位置 | 線條 | 蓋子 | 形狀 | 透明度 | 材質 |
  |---|---|---|---|---|---|
  | 櫃子上方 | 紅色 | 有 | 橢圓形 | 透明 | 玻璃 |

- 問法：「關於那個瓶子，哪一個說法**完全正確**？」
- 正解：挑 2～3 個真的元素組起來，例如「透明的玻璃瓶」。**正解不一定是最詳細的那個**。人傾向選描述得很詳細的選項，這本身就是一個陷阱。
- 誘答：每個選項只換掉**一個**元素。
  - 櫃子上方的**瓷**瓶（材質換掉）
  - **綠色**線條的玻璃瓶（綠色是紙條裡另一樣東西的顏色，屬於張冠李戴）
  - 有蓋子的**方形**玻璃瓶（形狀換掉）
- 換上的值，優先用**紙條裡別的東西**的值（張冠李戴），其次用常理值（常理陷阱），最後才用同類的其他值（差一點點）。
- 難度：元素數量從第 4 關的 3 個，逐步增加到第 8 關的 6 個。

#### B. 範圍與集合（好幾個都可以，只有一個選項在裡面）
- 例：花買**粉紅色、淡黃色或深紫色**都可以，就是**不要白色**。
- 問法：「哪一種花**可以**買？」四個選項中只有一個在集合裡。
- 正解：淡黃色。
- 誘答：把集合裡的字**拆開重組**。
  - 淡紫色（淡黃的「淡」＋深紫的「紫」）、深黃色、粉紫色：拼湊組合。
  - 白色（被明說不要的）：否定遺漏。

#### C. 反常理組合
- 例：**黃色**的玫瑰、**紅色**的菊花；**綠色**的蘋果、**紅色**的芒果。
- 誘答：
  - 常理版（紅玫瑰、黃菊花）：常理陷阱。
  - 兩者對調（黃色的菊花）：張冠李戴。
- 同一題裡，常理和另一樣東西兩股力量同時把人往錯的方向拉，是最強的混淆之一。

#### D. 文章化、加長
- 不編號、不分點。用家人的口吻寫，有前因後果、情緒、閒聊。
- 重點埋在句子中間，例如「老伴一邊穿鞋一邊說，魚要買兩條……」。
- 字數與頁數見 8.3。

#### E. 取消與更改
- 例：
  - 第 1 頁：買蔥、醬油、白醋。
  - 第 4 頁：「蔥不用了，改買薑；醬油要買金蘭的；白醋也不要了，改買工研的黑醋。」
- 題目以**最後的版本**為準，問法明講「最後要買……」。
- 誘答：
  - 被取消的：蔥、白醋（新舊混淆）。
  - 品牌對調：工研醬油、金蘭黑醋（張冠李戴）。
  - 新舊拼湊：金蘭白醋、工研白醋（拼湊組合）。
- 更改的位置和原句的距離：第 6 關在下一頁；第 7、8 關隔 2～4 頁。

#### F. 擾句（混淆文句）：看起來像重點，其實不是任務
- 故意寫得像重點：有數字、顏色、名稱。
  - 回憶：「上次買的蔥太粗，被念了好久。」
  - 旁人：「陳太太說二樓豬肉攤今天特價，一斤一百八十元。」（但這週不吃豬肉）
  - 比較：「媽媽說上次的奶油蛋糕很好吃，但是這次想吃巧克力口味。」
- 有兩種用途：
  - **誘答素材**：內容會出現在錯誤選項，例如「奶油蛋糕」（似曾相識）。
  - **純雜訊**：完全不會用到，只負責佔用腦容量。
- 規則：**擾句永遠不會被當成題目來問**，它的內容只會出現在錯誤選項裡。
- 比例：第 2 關一句，逐步增加到第 8 關約佔全文三分之一。

#### G. 講的順序 ≠ 做的順序（我補充）
- 例：
  - 「去郵局之前，記得先到銀行領錢。」
  - 「花最後回家前再買，不然會悶壞。」
- 問的是**做的順序**。照讀到的順序作答，就會錯（順序顛倒）。

#### H. 誰要的（人物歸屬，我補充）
- 例：「孫子要草莓牛奶，女兒要無糖豆漿，老伴什麼都不要，只交代別忘了拿藥。」
- 問：「無糖豆漿是誰要的？」
- 誘答：其他人（張冠李戴）。「人和東西」的綁定，正好是老化最先退化的能力（2.3）。

#### I. 同一件事換一種說法（第 7 關以上，可不用）
- 例：紙條寫「兩百五」「一斤半」「傍晚六點半」，選項寫「250 元」「1.5 斤」「18:30」。
- 考的是「懂了再記」，不是只記字面。

### 8.3 各關的紙條規格
實際量過：紙條用 34px 大字時，一頁約 **90 個字**（最小 26px 時約 166 字）。字數多就分頁，不捲動。

| 關 | 題數 | 約幾個字 | 約幾頁 | 寫法 | 用到的混淆寫法 |

| 1 | 4 | 40 | 1 | 條列（維持現在） | — |
| 2 | 6 | 150 | 2 | 口語短文，照順序講 | F（一句）、數字相近 |
| 3 | 8 | 220 | 3 | 口語短文 | G、F |
| 4 | 12 | 300 | 4 | 文章＋對話 | A（3 個元素）、C、F |
| 5 | 16 | 380 | 5 | 文章，兩個人各自交代 | A（4 個元素）、B、H、兩段相似行程 |

### 8.4 公平原則（每題都要有唯一正解）
1. 每題的答案，都能從紙條的**最後版本**確定。
2. 誘答必須和紙條**明確矛盾**，不能只是「沒提到」。例如紙條沒說瓶子大小，「大的玻璃瓶」就不能當誘答。
3. 更改一定明講（「不用買了」「改成」），不靠暗示。
4. 擾句不會被問。
5. 同一件事只問一次。換角度問才算另一題，例如「要買什麼醋？」和「工研是哪一樣的牌子？」。
6. 問題不照紙條的順序排。
7. 選項最多 10 個字（34px 字一行放得下）。
8. 只用日常生活常識，不考冷知識。

## 9. 題目與誘答怎麼產生（每局都變）

### 9.1 資料怎麼組成
- **一關＝一個故事範本＋一組參數。**
- **故事範本**：由人寫好的口語文章，裡面挖空，例如「{市場}」「{醬油.品牌}」「{瓶子.線條色}」。人寫的才能保證句子自然。每關準備 2～3 個不同故事輪流用，例如買菜、看醫生、孫子生日、去廟裡拜拜。
- **參數**：從題庫池抽。
  - 地點：真實的台北街名、市場、地標。
  - 東西：每樣都帶著自己的量詞，例如一**把**蔥、一**瓶**醬油、一**塊**薑、一**束**花，才不會出現「一瓶蔥」。
- **每樣東西拆成元素**：名稱、數量、顏色、形狀、材質、位置、品牌、是誰要的……
- **每個元素記住自己的歷史**：原本的值、改成的值、出現在紙條第幾頁。題目、誘答、答錯的說明，全部從這份資料自動產生。

### 9.2 誘答從哪裡來
每題的正解取自最後版本。三個誘答依下面順序挑，盡量來自兩種以上的類型：

| 優先 | 誘答來源 | 混淆類型 |
|---|---|---|
| 1 | 紙條裡**別的東西**的同類元素（別的顏色、別段的公車號、別人要的東西） | 張冠李戴 |
| 2 | 被取消、被改掉的原本版本 | 新舊混淆 |
| 3 | 擾句裡提過的內容 | 似曾相識 |
| 4 | 一般常理的值（紅蘋果、珠寶在 1 樓） | 常理陷阱 |
| 5 | 把兩個說法拆開重組（淡紫色、工研白醋） | 拼湊組合 |
| 6 | 數字對調或相近（236 → 263） | 數字相近 |
| 7 | 被明說「不要」的 | 否定遺漏 |
| 8 | 順序上相鄰的一件事 | 順序顛倒 |
| 9 | 同類的其他值（瓷瓶、方形） | 差一點點 |

### 9.3 結果頁：你最容易被哪一種混淆騙到
- 每個錯誤選項都帶一個類型。統計方式：**被這一類誘答騙到的次數 ÷ 遇到這一類誘答的題數**。這樣比較公平，因為有些類型出現得比較多。
- 結果頁顯示最容易上當的 2～3 種，每種附一句白話說明和一個本局的錯題例子，一頁放得下。
- 類型名稱用長者熟悉的說法：

| 類型 | 白話說明 |
|---|---|
| 張冠李戴 | 把 A 的特徵安到 B 身上 |
| 新舊混淆 | 選了已經被取消、被改掉的 |
| 似曾相識 | 選了只是順口提到的 |
| 常理陷阱 | 照一般習慣選，沒照紙條 |
| 拼湊組合 | 把兩個說法拼成一個 |
| 數字相近 | 數字對調或只差一點 |
| 否定遺漏 | 選了明說不要的 |
| 順序顛倒 | 先後弄反了 |
| 差一點點 | 大意對、細節錯 |
| 計算失誤 | 記得數字，但算錯了 |

### 9.4 答錯當下的回饋
- 標出正確答案，並用一句話說明來歷。句子依類型自動產生：

| 類型 | 說明句範例 |
|---|---|
| 新舊混淆 | 「白醋」後來改掉了，最後是「工研黑醋」。 |
| 張冠李戴 | 牌子對調了：金蘭是醬油，工研是黑醋。 |
| 似曾相識 | 「奶油蛋糕」只是順口提到，這次要的是巧克力口味。 |
| 常理陷阱 | 蘋果一般是紅色的，但這次紙條寫的是「黃色」。 |
| 拼湊組合 | 「淡紫色」是把「淡黃」和「深紫」拼在一起了。 |
| 數字相近 | 263 和 236 很像，紙條上是 236。 |
| 否定遺漏 | 紙條特別說「不要白色」。 |

- 答錯時畫面停住，按「下一題」才繼續，讓長者看清楚正確答案。
- 同一關重玩時題目不變，玩家有機會把正確的版本記牢（4 的無錯誤學習）。

## 10. 範例：第 6 關（示意，還不是定稿）

### 紙條（約 400 字，34px 字約 5 頁）

> 明天是星期六，女兒一家要回來吃午飯。老伴早上出門前，站在門口交代你：「下午記得去南門市場買菜喔！先買一把蔥、一瓶醬油、一罐白醋。蔥要挑細一點的，上次你買的蔥太粗，炒起來一點都不香。」
>
> 她想了想又說：「魚要買兩條，一條鱸魚、一條虱目魚，虱目魚記得請老闆去刺。」隔壁的陳太太剛好經過，說市場二樓的豬肉攤今天特價，一斤只要一百八十元，不過你們家這個禮拜說好不吃豬肉。
>
> 水果要買黃色的蘋果兩顆、紅色的芭樂一顆，孫子最近只吃這兩種。對了，櫃子上方那個畫著紅色線條、有蓋子的橢圓形透明玻璃瓶，是女兒最喜歡的點心瓶，裡面的綠色芒果乾快吃完了，順便補滿。
>
> 你正要出門，老伴又打電話回來：「蔥不用買了，冰箱還有，改買一塊薑。醬油要買金蘭的；白醋也不要了，改買工研的黑醋。」掛電話前她又補一句：「花也順便帶一束，粉紅色、淡黃色或深紫色都可以，就是不要白色的。」

用到的寫法：
- D：文章化。
- E：第 4 段改掉第 1 段。
- A：瓶子有 6 個元素。
- B：花的顏色是一個範圍。
- C：黃蘋果、紅芭樂、綠芒果乾。
- F：擾句，包括蔥太粗、陳太太、豬肉特價。
- H：孫子、女兒、老伴各自有關的東西。
