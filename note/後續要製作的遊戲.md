# "色不異空" 
左邊一個長方形色塊，右邊一個同樣大小的長方形色塊，兩個之間隔著一條相同高度的黑色長方形(寬度100px)，盡量滿版充滿遊戲畫面。
兩者的色相或彩度或亮度(三擇一)是不同的。右邊的長方形會持續改變顏色的色相或彩度或亮度(三擇一，與上述相同)。
畫面下方顯示白字"當你覺得兩個方塊顏色是完全相同時，\n請點擊畫面確認。"
讓玩家以肉眼觀察 覺得左右兩個方塊的顏色是完全相同時，點擊畫面任一處，兩個方塊會互相靠近緊貼，畫面下緣改成顯示兩個方塊的"顏色差異度 XX.XX%"(大尺寸字體) ，並顯示"再玩一次"的按鈕。


# "七彩陷阱"
畫面有2*2 四格正方形互相緊鄰，黑底，一開始四格都是黑色。
畫面上緣顯示"請點擊🔴紅方塊，超時就失敗。"(固定字體，白色，不要太大，佔據畫面上方約10%空間)
從左上角開始將方塊改成隨機的七彩顏色(固定的七個鮮豔的七彩顏色) 每0.5秒(時間間隔會越來越短) 換下一個方塊(從左上角、右上角、右下角、左下角、左上角…)改變顏色。
最新出現的方塊要顯示白邊(表示是最新的方塊)，上一個方塊要隱藏顯示白邊(顯示下一個方塊之後，上一個方塊的白邊要消失)。
如果出現紅色方塊 玩家必須立刻點擊紅色方塊，若超時就算失敗。
當方塊顏色不是紅色時會隨機出現紅色或白色或黑色的"紅"壓在色塊上來干擾玩家，字的寬度約方塊的80% 粗體。
出現第12個(請寫成變數讓我自己調整數量)紅色方塊之後，遊戲先暫停，規則改變成 除了紅色之外隨機添加另一種顏色(例如綠色)的方塊，玩家必須點擊紅色方塊跟綠色方塊。當方塊顏色不是紅色或綠色時會隨機出現紅色或綠色或白色或黑色的"紅"或"綠"字壓在色塊上來干擾玩家。跳出彈窗顯示新規則來提醒玩家，玩家可以點擊彈窗的"知道了(5)"按鈕來關閉彈窗，"知道了(5)"中的(5)會倒數到0消失，5秒之後彈窗自動消失。畫面上緣的提示文字也會改成"請點擊🔴紅🟢綠方塊，超時就失敗。"，依此類推，逐漸增加顏色數量至6個。
