怎麼用
  1. 打開就會自動查「7 天前到今天」的意見。要看別的時間、別的 id 範圍，就在「查詢條件」改，按「查詢」。時間用這台電腦的時區；「到」的那一分鐘整分鐘都算。
  2. 只想貼「遊戲、遊戲名稱、意見」給 Claude：勾「只顯示 game_id game_title message」。
  3. 不想貼的那幾列，把最左邊的勾勾取消。
  4. 按「複製」，到 Claude 的輸入框貼上。每一列一行、欄位用 Tab 隔開；意見裡的換行會變成「 ⏎ 」，這樣一則意見不會斷成好幾行。
  5. 貼完按「把目前結果的最大 id 記為已處理」；下次按「從 id N 開始查」，就只會看到新的意見。
  6. 查詢不需要金鑰：這個網頁用的是遊戲本來就公開的 anon 金鑰，只能讀公開檢視表 MF_feedback_public（不含玩家代號 player_id），不能新增、修改或刪除任何東西。
